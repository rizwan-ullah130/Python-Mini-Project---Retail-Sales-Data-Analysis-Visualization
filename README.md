# Retail Sales Data Analysis & Visualization

This is a quick data analytics project where I worked on a retail sales dataset to clean the data, find trends, and build some clean charts. The main goal was to understand which products, regions, and months drive the most sales and profits.

## What I Did in This Project

*   **Cleaned the Data:** Fixed missing fields, corrected data types, and made sure all numbers and amounts were properly formatted.
*   **Created Time Features:** Extracted useful details like the month name, quarter, and day of the week from raw date formats so I could analyze trends over time.
*   **Run Stats & Breakdowns:** Grouped the sales data to see exactly how different product categories (Books, Electronics, Clothing, etc.) and regions (West, East, North, South) are performing.
*   **Plotted the Data:** Used Matplotlib and Seaborn to build clear line charts for monthly trends and bar charts to compare different categories.

## Tools Used

*   Python (for the core logic)
*   Pandas & NumPy (for data manipulation)
*   Matplotlib & Seaborn (for the charts)

## Project Files

*   `Project1.ipynb` - The full Jupyter Notebook containing all the step-by-step cleaning code and charts.
*   `retail_sales.csv` - The raw data file used for the analysis.

## How to Run It

1. Clone the repo to your local machine:
   ```bash
   git clone https://github.com/rizwan-ullah130/Python-Mini-Project---Retail-Sales-Data-Analysis-Visualization.git
   ```
2. Make sure you have the required libraries installed:
   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
